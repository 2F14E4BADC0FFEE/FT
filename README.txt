================================================================================
   DFSS Statistics Fine-Tuning Studio — Complete Setup Guide
================================================================================

   Fine-tune a local AI model on a DFSS Statistics textbook (369 pages)
   and chat with it — entirely on your laptop, no GPU required.

   Model:    DeepSeek-R1 1.5B (or 7B with 32+ GB RAM)
   Method:   LoRA fine-tuning with HuggingFace PEFT
   Dataset:  193 Q&A pairs generated by Claude
   Output:   Local Ollama model "deepseek-dfss"


================================================================================
   WHAT YOU NEED
================================================================================

   - Windows 10/11 (also works on macOS/Linux)
   - 16 GB RAM minimum (32 GB recommended)
   - ~20 GB free disk space
   - Internet connection (for first-time downloads only)
   - No GPU required — everything runs on CPU


================================================================================
   STEP 1: Install Anaconda (if not already installed)
================================================================================

   Download from: https://www.anaconda.com/download
   Install with default settings.


================================================================================
   STEP 2: Create the Conda Environment
================================================================================

   Open Anaconda Prompt (search "Anaconda Prompt" in Start Menu).

   Option A — Using the provided YML file (recommended):

       conda env create -f LLM_FineTune_local.yml

   Option B — Manual creation (if YML not available):

       conda create -n LLM_FineTune_local python=3.11 -y
       conda activate LLM_FineTune_local

       pip install torch --index-url https://download.pytorch.org/whl/cpu
       pip install transformers peft datasets trl accelerate
       pip install sentencepiece protobuf huggingface-hub
       pip install gradio requests jupyter

   Activate the environment (do this every time you open a new terminal):

       conda activate LLM_FineTune_local


================================================================================
   STEP 3: Install Ollama
================================================================================

   3a. Download and install Ollama:

       https://ollama.com/download

       Run the installer. Ollama runs as a background service.

   3b. Verify Ollama is running. Open a NEW terminal (PowerShell or cmd):

       ollama --version

       You should see something like: ollama version 0.x.x

   3c. Pull the base model:

       ollama pull deepseek-r1:1.5b

       This downloads ~1 GB. Wait until it finishes.

   3d. Test the base model:

       ollama run deepseek-r1:1.5b "Hello, what is statistics?"

       You should get a response. Type /bye to exit.


================================================================================
   STEP 4: Set Up the Project Folder
================================================================================

   4a. Create a project folder (or use the provided one):

       mkdir C:\DFSS_FineTuning
       cd C:\DFSS_FineTuning

   4b. Place the following files in the project folder:

       C:\DFSS_FineTuning\
         DFSS_FineTuning_Studio.ipynb          <-- the main notebook
         LLM_FineTune_local.yml                <-- conda environment file

         finetune_pipeline_v2\                  <-- dataset folder
           04_qa_final.json                     <-- 193 Q&A pairs (master)
           05_train_chatml.jsonl                <-- training format
           05_train_plain.txt                   <-- plain text format
           05_train_split.jsonl                 <-- train split (173)
           05_val_split.jsonl                   <-- validation split (20)


================================================================================
   STEP 5: Launch the Notebook
================================================================================

   5a. Open Anaconda Prompt:

       conda activate LLM_FineTune_local
       cd C:\DFSS_FineTuning
       jupyter notebook DFSS_FineTuning_Studio.ipynb

   5b. Run all 4 cells in order (Shift+Enter for each):

       Cell 1: Imports & package check (should show all green)
       Cell 2: Configuration (edit paths if needed)
       Cell 3: Core functions (loads dataset)
       Cell 4: Launches the Gradio web app

   5c. The Gradio app opens in your browser at:

       http://127.0.0.1:7860

================================================================================
   TROUBLESHOOTING
================================================================================

   PROBLEM: "Ollama not running"
   SOLUTION: Open a terminal and run: ollama serve
             Or restart your computer (Ollama starts automatically)

   PROBLEM: "ModuleNotFoundError: No module named 'transformers'"
   SOLUTION: Make sure you activated the conda environment:
             conda activate LLM_FineTune_local

   PROBLEM: Training crashes with "out of memory"
   SOLUTION: In the Train tab, reduce:
             - Max Seq Length → 256
             - LoRA Rank → 8
             - Gradient Accumulation → 4

   PROBLEM: Training is very slow
   SOLUTION: Set Max Steps to 50-100 for a shorter run
             Or reduce Epochs to 1

   PROBLEM: "Convert to GGUF" fails
   SOLUTION: You need llama.cpp. Install it:
             git clone https://github.com/ggerganov/llama.cpp.git
             pip install -r llama.cpp/requirements.txt
             Then try the button again.

             Or run manually:
             python llama.cpp/convert_hf_to_gguf.py finetune_pipeline_v2\deepseek-dfss-merged --outtype q4_k_m --outfile finetune_pipeline_v2\deepseek-dfss-Q4_K_M.gguf

   PROBLEM: "Import to Ollama" fails
   SOLUTION: Run manually in terminal:
             cd finetune_pipeline_v2
             echo FROM deepseek-dfss-Q4_K_M.gguf > Modelfile
             ollama create deepseek-dfss -f Modelfile

   PROBLEM: Model gives wrong/weird answers
   SOLUTION: The 1.5B model has limited capacity. Try:
             - Train more epochs (5 instead of 3)
             - Use the 7B model (needs 32+ GB RAM):
               Edit Cell 2, change MODEL_NAME to:
               "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"

================================================================================
   DATASET COVERAGE
================================================================================

   The 193 Q&A pairs cover all chapters of the DFSS Statistics textbook:

   Chapter              Q&A Pairs   Topics
   ─────────────────────────────────────────────────────────────────────
   Probability theory      ~18      Sets, Laplace, Kolmogorov, Bayes
   Descriptive stats       ~14      Mean, variance, histograms, box plots
   Distributions           ~20      Normal, binomial, Poisson, t, F, chi²
   Confidence intervals     ~5      Known/unknown variance, prediction
   Hypothesis testing      ~12      Type I/II, p-value, t-test, F-test
   ANOVA                    ~6      Single/multi-factor, post-hoc
   Correlation              ~4      r, R², causation vs correlation
   Regression              ~12      Least squares, significance, bands
   Applications             ~8      SPC, Six Sigma, MSA
   Cross-topic             ~20      Comparisons, calculations, errors
   + Paraphrases           ~12      Alternative phrasings for diversity
   + Derivations            ~3      Mathematical proofs

   Types: definition (26%), conceptual (22%), calculation (18%),
          application (11%), comparison (10%), error analysis (7%),
          factual (4%), derivation (2%)

   Difficulty: easy (21%), medium (58%), hard (21%)

     Quick test (20 steps):   10-15 min

   Export:
     Merge LoRA:           2-5 min
     Convert to GGUF:      5-10 min
     Import to Ollama:     < 1 min

   Total first run:        ~3-6 hours
   Subsequent runs:        ~2-5 hours (packages cached)
